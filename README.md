## 项目

**[motion-replica](https://github.com/Leslie-ller/motion-replica)** · Python、Node.js、lottie-web、After Effects

双 Agent 复刻参考动效：主 Agent 写动画，检查 Agent 只看画面并指出哪个元素在什么时间不对，结果可编译回 AE。预览与 AE 逐帧比对，单帧平均误差不到 1/255；与一次生成对照，部分任务上元素出现时机的误差从 0.16 s 降到 0.04 s。

**[agentos-session-core](https://github.com/Leslie-ller/agentos-session-core)** · React、TypeScript、Rust、SQLite

基于 Codeg 的会话扩展：同一条对话里切换 Agent，交接可见上下文，保留每条回复的来源和各 Agent 的原生会话。在 Claude Code、Codex、Devin 之间的 30 次任务接续实测中，成功 27 次（90%）。

**[classroom-discussion-review](https://github.com/Leslie-ller/classroom-discussion-review)** · Python、SQLite

课后讨论复盘模块：读取原题和完整讨论，分开核查答案、理由和适用条件，找出仍未解决的问题并生成补充讲解。
